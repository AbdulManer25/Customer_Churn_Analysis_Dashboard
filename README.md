# 📊 Customer Churn Analysis Dashboard

A Power BI dashboard designed to analyze customer churn behavior, identify risk factors, and provide actionable business insights to improve customer retention.

---

## 🚀 Project Overview

Customer churn is a critical business metric for subscription-based companies. This project analyzes customer data to uncover churn patterns, retention trends, and revenue impact.

The dashboard provides insights into:

* Customer retention and churn rates
* Contract-based churn analysis
* Customer tenure behavior
* Revenue contribution by customer segments
* Service adoption impact on churn
* Risk-based customer segmentation

## 📊 Dashboard Insights

### Customer Retention Overview

* Retained Customers: **5,174 (73.46%)**
* Churn Customers: **1,869 (26.54%)**

This indicates that approximately **1 in every 4 customers** has churned.

---

### Churn Rate by Tenure Band

| Tenure Band | Churn Rate |
| ----------- | ---------- |
| 0–6 Months  | 52.94%     |
| 6–12 Months | 35.89%     |
| 12+ Months  | 17.13%     |

**Insight:** Customers are most likely to churn during their first six months.

---

### Churn Customers by Contract Type

| Contract Type  | Churn Customers |
| -------------- | --------------- |
| Month-to-Month | 1,655           |
| One Year       | 166             |
| Two Year       | 48              |

**Insight:** Nearly **89% of churned customers** belong to Month-to-Month contracts.

---

### Monthly Charges Analysis

| Customer Type      | Monthly Charges |
| ------------------ | --------------- |
| Existing Customers | ₹375.03K        |
| New Customers      | ₹81.08K         |

**Insight:** Existing customers contribute over **4.6× more revenue** than new customers.

---

### Online Security & Backup Analysis

| Service Category    | Monthly Charges |
| ------------------- | --------------- |
| No Security         | ₹264.72K        |
| Security Enabled    | ₹159.15K        |
| No Internet Service | ₹32.24K         |

**Insight:** Customers without Online Security services show higher churn tendencies.

---

### Risk-Based Customer Segmentation

| Risk Category | Customers |
| ------------- | --------- |
| Normal Risk   | 4,541     |
| High Risk     | 633       |

**Insight:** High-risk customers should be prioritized for retention campaigns.

## 💡 Recommendations

### 1. Improve Customer Onboarding

Since customers churn the most during the first 6 months:

* Create onboarding campaigns
* Offer proactive support
* Provide personalized guidance

### 2. Promote Long-Term Contracts

* Offer annual subscription discounts
* Introduce loyalty rewards
* Encourage contract upgrades

### 3. Increase Service Adoption

Promote:

* Online Security
* Online Backup
* Premium Support Services

### 4. Focus on High-Risk Customers

* Identify high-risk customers early
* Run targeted retention campaigns
* Monitor churn indicators regularly
